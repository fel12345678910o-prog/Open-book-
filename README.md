# Open Book 📖

موقع مؤتمر Open Book.

## النشر السريع مجانًا على GitHub Pages
1. أنشئ حسابًا على GitHub.
2. أنشئ Repository جديدًا باسم مناسب.
3. ارفع ملف `index.html` و `style.css`.
4. من Settings > Pages اختر النشر من Branch `main`.
5. سيظهر لك رابط الموقع.

الموقع جاهز ويعمل على الموبايل والكمبيوتر.
